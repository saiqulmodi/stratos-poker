# Code of Conduct

## Our pledge

Everyone who plays, reports issues or contributes to Stratos Poker Arena should be able to do so without harassment, whatever their age, background, identity, experience or level of skill.

## Expected behaviour

- Be respectful and kind, at the table chat and on GitHub.
- Give and accept feedback politely; focus on the problem, not the person.
- Respect other players' privacy. Never post anyone's email id, phone number or other personal details.

## Unacceptable behaviour

- Insults, harassment, threats or hateful language.
- Sexual language or imagery.
- Spam, cheating tools, collusion or abuse of bugs to win chips.
- Publishing other people's private information.

## Enforcement

Report problems to the maintainer by opening a GitHub issue (or privately as described in [SECURITY.md](SECURITY.md) for sensitive matters). The maintainer may remove comments, close issues, or block accounts that break this code.

This code is adapted from the ideas of the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
