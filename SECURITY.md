# Security Policy

## Supported versions

Only the latest code on the `main` branch (the live server) receives security fixes.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report them privately through GitHub: **Security and quality -> Advisories -> Report a vulnerability** on this repository, or by email to the maintainer at saiqulmodi@gmail.com.

Please include:

- what the problem is and where (file, endpoint or page),
- steps to reproduce,
- the possible impact (for example: reading other players' details, changing chip counts, taking over a seat).

You can expect a first reply within 7 days. Please give a reasonable time to fix the problem before telling anyone else about it.

## Player data

Players' email ids and phone numbers are stored only in the server's local database, which is never committed to this repository.
